Векторы (std::vector) и строки (std::string)

Вектор и строка — базовые контейнеры стандартной библиотеки C++. Они хранят элементы в непрерывном фрагменте памяти, обеспечивают быстрый доступ по индексу ($O(1)$) и эффективное добавление элементов в конец.

Контейнер std::vector

Динамический массив, меняющий свой размер при необходимости. Для работы требуется заголовок <vector>.

Объявление

Элементы вектора должны быть одного типа $T$, известного на этапе компиляции:

cpp
Копировать
#include <vector>
#include <string>

// Вектор целых чисел
std::vector<int> numbers = {1, 2, 3};

// Вектор строк
std::vector<std::string> words;

std::vector — это шаблон класса. Тип элемента задается в угловых скобках.

Доступ к элементам
По индексу (без проверки):
cpp
Копировать
std::vector<int> data = {10, 20, 30};
int first = data[0];      // 10
data[1] = 99;             // Изменение: {10, 99, 30}
// data[5];               // Undefined Behavior!
Безопасный доступ (at): выбрасывает исключение std::out_of_range, если индекс неверен.
cpp
Копировать
try {
    std::cout << data.at(5);
} catch (const std::out_of_range& e) {
    std::cerr << "Index out of bounds\n";
}
Границы: front(), back(). Вызов этих функций на пустом векторе приводит к UB.
Свойства: size() (количество элементов), empty() (проверка на пустоту).
Итерация

Использование беззнакового типа size_t для индексов может привести к переполнению при вычитании из нуля. 
Решение: использовать проверку через сложение или знаковый тип std::ssize (C++20).

cpp
Копировать
// Каноническая форма цикла по индексам
for (size_t i = 0; i != data.size(); ++i) {
    std::cout << data[i] << ' ';
}

// Безопасная проверка соседних элементов (не ломается на size == 0)
for (size_t i = 0; i + 1 < data.size(); ++i) {
    if (data[i] == data[i + 1]) {
        std::cout << "Duplicate: " << data[i] << '\n';
    }
}
Добавление, удаление и управление памятью
Добавление/удаление с конца:
push_back(value) — эффективно добавляет элемент.
pop_back() — удаляет последний элемент.
Очистка: clear() удаляет все элементы, но обычно сохраняет выделенную память (capacity).
Резервирование: Чтобы избежать дорогих реаллокаций (копирования всех элементов в новый блок памяти), используйте reserve(N). Она увеличивает зарезервированную емкость, не меняя логический размер.
cpp
Копировать
std::vector<std::string> dict;
dict.reserve(1000); // Зарезервировали место под 1000 слов
for (int i = 0; i < 1000; ++i) {
    dict.push_back("word" + std::to_string(i)); // Реаллокаций не будет
}
Изменение размера: resize(N) меняет количество элементов. Если $N$ больше текущего размера, новые элементы инициализируются дефолтным значением.
Сортировка

Для сортировки используется алгоритм <algorithm>:

cpp
Копировать
#include <algorithm>

std::vector<int> v = {3, 1, 4, 1, 5};
std::sort(v.begin(), v.end());          // По возрастанию: 1, 1, 3, 4, 5
std::sort(v.rbegin(), v.rend());        // По убыванию: 5, 4, 3, 1, 1
// C++20:
// std::ranges::sort(v);

Сравнение самих векторов лексикографическое (как слова в словаре).

Строки (std::string)

Контейнер символов char со специализированными функциями. Требует заголовок <string>. Можно рассматривать как std::vector<char>.

Базовые операции
cpp
Копировать
#include <string>
#include <iostream>

std::string s = "Some string";

// Конкатенация
s += ' ';           // Аналог push_back
s += "functions";   
std::cout << s << "\n"; // Some string functions

// Выделение подстроки
std::string sub1 = s.substr(5, 6); // "string" (6 символов с индекса 5)
std::string sub2 = s.substr(12);   // "functions" (до конца строки)

// Поиск
size_t pos_space = s.find(' ');         // 4
size_t pos_not_found = s.find('#');     // std::string::npos
Модификация
cpp
Копировать
std::string s = "Some string functions";

// Вставка
s.insert(5, "std::");                   // Some std::string functions

// Замена диапазона
s.replace(0, 4, "Special");             // Special std::string functions

// Удаление
s.erase(8, 5);                          // Special string functions
Возможности C++20

Проверка префикса и суффикса одной командой:

cpp
Копировать
if (phrase.starts_with("hello")) {
    std::cout << "Greeting\n";
}

if (phrase.ends_with("bye")) {
    std::cout << "Farewell\n";
}

cpp
Копировать
#include <string>

int number = 42;
std::string str_num = std::to_string(number); // "42"

std::string from_user = "12345";
int parsed = std::stoi(from_user);            // 12345
Полезные советы
Не смешивайте знаки: Из-за правил приведения типов выражение vec.size() - 1 на пустом векторе даст огромное положительное число (size_t). Используйте !vec.empty() && vec.back() == ... или цикл while.
Избегайте преждевременной оптимизации: Не вызывайте reserve() без измерений, если вектор содержит менее нескольких тысяч элементов — аллокаторы современных STL очень быстры.
Храните тяжелые объекты через указатели: Если объект дорогой для копирования, используйте std::vector<std::unique_ptr<MyClass>>, чтобы при реаллокациях вектора перемещались только легкие указатели, а не сами объекты.
Используйте структурную привязку (C++17) при итерации по матрице:
cpp
Копировать
std::vector<std::vector<int>> matrix = {{1, 2}, {3, 4}};
for (auto& [col1, col2] : matrix) {
    // работаем напрямую с элементами строки
}
